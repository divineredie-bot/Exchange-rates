# Exchange Rate

Веб-приложение для конвертации валют с использованием актуальных обменных курсов.

## Возможности

- Выбор исходной и целевой валюты
- Конвертация валют в реальном времени
- Переключение исходной и целевой валют с помощью кнопки Swap
- Получение актуальных обменных курсов через внешний API
- Динамический расчёт значения выбранной валюты
- Работа с большим количеством валют

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- REST API
- ExchangeRate-API
- DOM API

## Особенности реализации

Обменные курсы не хранятся в коде в виде статических значений. Приложение получает актуальные данные через ExchangeRate-API, поэтому конвертация основывается на данных API, а не на заранее заданных курсах.

Реализована возможность выбора двух валют и их быстрого обмена местами с помощью кнопки Swap.
